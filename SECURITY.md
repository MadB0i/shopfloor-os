# Security

This repository is an open event-log core. It is not a hardened multi-tenant SaaS.

- Demo bearer tokens are public by design. Replace them before any network that is not your laptop.
- Do not file issues that include real operator names, customer SKUs, or plant photos.
- To report a vulnerability in ingest, auth, or SQL: open a GitHub security advisory on the repo (once published) or email the maintainer listed on the GitHub profile. Do not open a public issue with an exploit.

There is no cloud account attached to this project. GitHub hosting is the only distribution channel intended for the source.

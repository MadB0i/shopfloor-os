# Visual constraints (UI later)

The HTTP API has no look. When a client appears, it must not read as a generic generated SaaS kit.

## Allowed

- Dense tables, stamp-like IDs (`WO-24-0841`, `M-PRESS-01`)
- Four colors at most: machine grey, oxide, safety yellow, one CRT green
- Grotesque for labels, monospace for IDs, quantities, timestamps
- Persistent chrome: plant, shift clock, ingest health (ok / degraded)
- ISO-like marks for lockout / hazard, not cartoon robots

## Forbidden

- Purple gradients, glass cards, blob meshes, stock “smart factory” photos
- Inter-on-everything marketing heroes
- Bounce animations; live state is a lamp, not a Lottie
- Invented 3D machines or neural-net wallpaper

Reference mix: airport FIDS board, CNC controller, packing list. Instrument, not landing page.
